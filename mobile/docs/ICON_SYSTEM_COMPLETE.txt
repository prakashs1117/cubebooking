🚀 HOW TO ADD NEW ICONS (SUPER EASY!):

Step 1: Add your SVG file
  cp your-new-icon.svg src/assets/svg-broken-icons/

Step 2: Run the conversion script
  npm run convert-icons

Step 3: Use it immediately!
  import { YourNewIcon } from '@assets/svg-broken-icons';
  <YourNewIcon width={24} height={24} color="#007AFF" />

That's it! The script:
  ✅ Converts SVG to React Native
  ✅ Adds TypeScript interfaces
  ✅ Updates index.ts exports
  ✅ Makes it ready to use
