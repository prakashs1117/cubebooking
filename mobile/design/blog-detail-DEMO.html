Integration Guide

To integrate into the main Employee Connect app:

  1. Import CSS from blog-detail.html into your app stylesheet
  2. Import JavaScript functions: openBlogModal(), closeBlogModal()
  3. Add click handler to blog posts in feed: onclick="openBlogModal()"
  4. Wire up comment API calls (replace submitComment() dummy logic)
  5. Replace mock data with real article data from backend
  6. Test on mobile and tablet viewports
