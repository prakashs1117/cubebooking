Which sections should appear on Home?

Search bar is fixed at top. Select all the sections you want below it — you can pick multiple.

1

🕒 Recently Viewed Articles

Horizontal chip strip — SDS articles the user last viewed. Already live on home today.

Source: AsyncStorage (local) · Component: RecentArticlesStrip · Zero extra work
2

🔎 Recent Searches

Pill chips of past search terms — tap to instantly re-run. Currently only on Favorites tab.

Source: AsyncStorage (local) · Component: RecentSearchesStrip · Drag & drop from Favorites
3

⚡ Quick Actions

Icon-tile row: Safety Label · Scan Barcode · My Favorites. One tap to a core feature.

Translation keys already exist · Needs a new small QuickActionsRow component
4

📅 Upcoming Events

Horizontal scrollable event cards showing LIVE / UPCOMING events. Hides itself when no events exist.

Source: Events API · Component: UpcomingEventsCarousel · Already fully built
5

🃏 Curated Horizontal Cards

Editorial image cards with category tags (Oncology, Neuroscience…). "Recommended for You" feel.

Source: curatedHomeData.json (local) · Component: HorizontalCardsSection · Already fully built
6

📰 Daily Insights

Vertical list of articles with thumbnail, category dot, title, and read-time. "Daily briefing" feel.

Source: curatedHomeData.json (local) · Component: VerticalInsightsSection · Already fully built
💡 Tip: Select as many as you want. We'll decide ordering and visual weight in the next step.
